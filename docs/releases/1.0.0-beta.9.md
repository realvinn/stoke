Stoke 1.0.0 beta 9: Grok Bot workspace and chat tools

Grok Bot now opens as an agent choice in Stoke, with a searchable bot list on the left and a dedicated chat workspace for your saved Cursor or Grok accounts.

- **Bots on the left:** switch accounts, browse bots and groups, search, show hidden bots, and collapse the list for more chat space. Drafts and unconfirmed-delivery warnings follow their account and bot, including when you move the tab to another Stoke window.
- **Readable conversations:** Markdown replies, code blocks, tables, lists, copying, distinct author labels, preserved user line breaks, recent-history choices of 40/100/200 entries, and optional live updates. The chat follows new messages while you are near the bottom.
- **Bot and group management:** create bots or groups, edit names, titles and descriptions, change notifications and visibility, replace group members, and explicitly confirm deletion.
- **Shared skills:** view the selected account’s shared library, add SKILL.md contents, and confirm removal of library skills. Team-managed and plugin skills stay managed at their source.
- **Action approvals:** inspect current pending requests, Allow once or Deny. The CLI rechecks each request before submitting a decision, refuses stale cards and requires the official app to accept truncated details. Stoke never auto-approves these requests.
- **Computer handoff:** the Computer page opens the official Grok Bot desktop app. Verify its signed-in account matches the nickname shown in Stoke, then use Computer → Take over to control the hosted desktop. Viewing and control happen in Grok Bot; this beta does not embed a desktop stream in Stoke or switch the desktop app’s login.
- **Import and send fixes:** clearer desktop-session errors and restart guidance, removal of stale import choices, and recognition of current gateway send acknowledgements. Unconfirmed messages remain drafts with a check-before-resending warning.

Enable Grok Bot under Settings → Plugins, import each desktop login as a separate account, install the reviewed CLI, then choose New session → Other agents → Grok Bot. The integration uses the integrity-pinned unofficial grok-bot-cli 0.12.4; it runs each command with the selected account’s sealed session. Disabling the plugin removes its launcher choice, controls and conversation tabs.

Chat tabs and drafts remain in memory and are not restored after quitting Stoke. Up to 16 other bot drafts are retained per workspace. Recent history is limited to the latest 200 entries, and this release does not expose every feature of the official Grok Bot app. Account syncing remains opt-in and requires approved devices in the same encrypted vault.

Downloads cover macOS Apple silicon and Intel, Windows x64 and ARM64, and Linux x64.

Setup: [Grok Bot guide](https://github.com/realvinn/stoke/blob/v1.0.0-beta.9/docs/plugins.md#grok-bot-accounts)

Install this exact beta on macOS or Linux:

```sh
curl -fsSL https://stoke.vinn.dev | STOKE_VERSION=1.0.0-beta.9 sh
```

In Windows PowerShell:

```powershell
$env:STOKE_VERSION='1.0.0-beta.9'; irm https://stoke.vinn.dev/install.ps1 | iex
```
