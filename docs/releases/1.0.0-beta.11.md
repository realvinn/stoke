Stoke 1.0.0 beta 11: Per-tab terminals and complete links

This beta adds per-tab quick terminals, complete wrapped links and Windows account-cleanup fixes. It also includes the account, Notion and Grok Bot improvements from beta.10.

- **Windows account checks:** quitting Stoke stops its owned native account-check process tree and waits for cleanup. Windows batch launchers keep their descendants under cleanup ownership instead of leaving an account-check process behind. The helper uses precompiled native APIs and avoids cold PowerShell module imports during cleanup.
- **Long terminal links:** complete URLs survive soft wrapping beyond the web-link addon's 2 KiB search window and hard wrapping inside a padded CLI margin. Clicking either end opens the complete address, including its query. Short ambiguous lines still use Open selected link.
- **One Accounts entry:** Accounts lives at the bottom of the sidebar. Stoke sign-in and sync are separate from the account used by the current agent session. Choose an agent to manage its saved logins and API profiles. Changing the account for new sessions preserves the account used by running sessions.
- **Notion table picker:** enable Work, enter an integration token, then load or search the tables shared with that connection. Choose separate task and daily-work tables before inspecting their properties and saving the mapping. Discovery reads metadata; publishing remains an explicit reviewed action.
- **Quick terminal:** each tab keeps its own local shells, output and running commands. Pin a terminal to keep it across tabs; unpin to return to the active tab's shell. Choose an installed shell, keep it running while hidden, or move it into a separate window. Terminal is always available from the sidebar and can be added to the editable top bar. Startup starts no shell.
- **Grok Bot accounts:** Read desktop sessions shows all saved native logins and distinguishes them from exported computer connections. Missing or expired connections remain visible with reconnect instructions. Separate desktop data folders can be selected. Imported sessions remain encrypted and commands use the selected Stoke profile.
- **Codex usage-reset watcher:** an opt-in local watcher can wait for a usage-reset time before submitting Continue or a custom message. Typing cancels pending submission; active or normally completed turns stop the watcher. [Watcher guide](https://github.com/realvinn/stoke/blob/v1.0.0-beta.11/docs/codex-resume.md).
- **Packaged-app verification:** separate launches use separate debugging ports, and endpoint requests have bounded timeouts, so a stale test socket cannot prevent relaunch verification.

Grok Bot desktop control still uses the official desktop app. Cross-device account sync is opt-in and requires approved devices in the same encrypted vault; other native/keyring logins require sign-in on each device. The full product roadmap remains in progress, including privilege helpers and the standalone terminal companion. See [implementation status](https://github.com/realvinn/stoke/blob/v1.0.0-beta.11/docs/roadmaps/2026-10-08-execution.md).

Downloads cover macOS Apple silicon and Intel, Windows x64 and ARM64, and Linux x64.

Setup: [Plugin and Notion guide](https://github.com/realvinn/stoke/blob/v1.0.0-beta.11/docs/plugins.md), [account sync](https://github.com/realvinn/stoke/blob/v1.0.0-beta.11/docs/account-sync.md).

Install this exact beta on macOS or Linux from a terminal outside Stoke:

```sh
curl -fsSL https://stoke.vinn.dev/install.sh | STOKE_VERSION=1.0.0-beta.11 sh
```

In Windows PowerShell:

```powershell
$env:STOKE_VERSION='1.0.0-beta.11'; irm https://stoke.vinn.dev/install.ps1 | iex
Remove-Item Env:STOKE_VERSION
```

For in-app updates, enable beta releases under Settings → Updates, then check for updates.
