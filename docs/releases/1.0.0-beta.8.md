Stoke 1.0.0 beta 8: encrypted account sync and Grok Bot desktop imports

Saved agent accounts can now sync between approved Stoke devices. This release also fixes the desktop-session format error when importing current Grok Bot logins.

- **Opt-in account sync:** enable “Sync agent accounts across devices” under Settings → Accounts → Stoke account → Manage account & sync. Named profiles, API credentials, compatible Codex file-cache logins and saved Grok Bot production sessions travel through your encrypted vault. Each computer keeps its existing login homes and selected account. Both devices need beta.8 or later and must be approved in the same vault.
- **Grok Bot import fix:** supports the v3 descriptor written by Grok Bot 0.70.2, along with older formats. Import the chosen Cursor or Grok desktop session as a separate encrypted account. Expired snapshots show instructions to refresh the intended desktop login. Source discovery leaves desktop files unchanged.
- **Selected subscription accounts:** launch and identity checks use the selected account's authentication even when global API or gateway settings are configured.
- **Windows quick terminal:** a slow PATH refresh no longer consumes the shell startup deadline. Fresh paths remain available for subsequent launches.

Codex keyring/ephemeral logins and other native logins, including Claude subscription logins, sync profile details and still require sign-in on each computer. Account sync starts off; turning it on requires an approved encrypted vault. Grok Bot remains a separate plugin that each device enables explicitly. Bot access and Cursor/Grok coding CLI access use separate account selections. A shared provider connection registry remains future work.

Downloads cover macOS Apple silicon and Intel, Windows x64 and ARM64, and Linux x64. Linux credential storage requires a working OS Secret Service.

Setup: [account sync](https://github.com/realvinn/stoke/blob/v1.0.0-beta.8/docs/account-sync.md) · [Grok Bot accounts](https://github.com/realvinn/stoke/blob/v1.0.0-beta.8/docs/plugins.md#grok-bot-accounts)

Install this exact beta on macOS or Linux:

```sh
curl -fsSL https://stoke.vinn.dev | STOKE_VERSION=1.0.0-beta.8 sh
```

In Windows PowerShell:

```powershell
$env:STOKE_VERSION='1.0.0-beta.8'; irm https://stoke.vinn.dev/install.ps1 | iex
```
