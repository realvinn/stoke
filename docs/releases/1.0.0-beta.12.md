Stoke 1.0.0 beta 12: Remote function keys and modifiers

Use Byobu, VPS terminals and coding agents from Stoke's remote website with a touch-friendly key bar.

- **Function keys:** open F1–F12 directly, including modified function keys for Byobu windows, splits and detach controls.
- **Shift, Ctrl and Alt:** tap for one key, double-tap to lock, or hold a modifier with one finger while pressing another key. Shift → Left sends the combination requested by Codex.
- **Navigation and editing:** all four arrows, Escape, Tab and Enter are in the main controls. More opens Home, End, Page Up/Down, Insert, Delete, Backspace and the existing control shortcuts. Hold arrows or Backspace to repeat.
- **Phone ergonomics:** touch-sized targets, visible modifier state, sticky modifiers and internally scrolling groups keep controls reachable on small screens. Moving keyboard focus into the controls keeps them open.
- **Connection handling:** input goes only to a connected terminal. Disconnecting, hiding the controls or leaving the page clears held modifiers and repeats; keys are never replayed after reconnect. Ctrl+D still requires a second deliberate tap.

The website is served by your Stoke host computer. Update Stoke **on that host**, then reload the remote page to get the controls. Updating the phone or browser alone does not update the host's website.

[Remote keyboard guide and Byobu examples](https://github.com/realvinn/stoke/blob/v1.0.0-beta.12/docs/remote-keyboard.md).

Includes the per-tab terminals, wrapped-link fixes, account improvements and other changes from beta.11. The broader [implementation roadmap](https://github.com/realvinn/stoke/blob/v1.0.0-beta.12/docs/roadmaps/2026-10-08-execution.md) remains in progress.

Downloads cover macOS Apple silicon and Intel, Windows x64 and ARM64, and Linux x64.

Install this exact beta on macOS or Linux from a terminal outside Stoke:

```sh
curl -fsSL https://stoke.vinn.dev/install.sh | STOKE_VERSION=1.0.0-beta.12 sh
```

In Windows PowerShell:

```powershell
$env:STOKE_VERSION='1.0.0-beta.12'; irm https://stoke.vinn.dev/install.ps1 | iex
Remove-Item Env:STOKE_VERSION
```

For in-app updates, enable beta releases under Settings → Updates, then check for updates.
