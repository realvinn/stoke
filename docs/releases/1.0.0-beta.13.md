Stoke 1.0.0 beta 13: Other devices in the remote website

Open **Devices** in the remote website to see your approved Stoke computers that are online, then open a shared running session on one of them.

- **One website, several devices:** the current computer stays available alongside your other online devices, their running sessions, status and context. The target device remains named in the terminal header.
- **Existing permissions:** the target's session-sharing switch, approval prompt and view-only or full-control grant still apply. The website uses the host computer's existing encrypted device relay; account credentials and device keys stay on that computer.
- **Independent connections:** closing a browser connection leaves the target session and existing desktop connections running. Each browser owns its own relay, even when several connections open the same session.
- **Typing stays scoped:** drafts belong to both the device and session. Disconnected or view-only sessions never queue text for a later connection. Refusals retain their reason and offer a deliberate retry.
- **Remote terminal controls:** F1–F12, Shift/Ctrl/Alt, all four arrows, editing keys and paced message submission work across devices. Fit to phone requires a target that grants control and supports resizing. A toolbar used just after Send stays open.
- **Visible shell prompts:** opening terminal controls follows the last content row or cursor, keeping short shell prompts visible without scrolling through unused terminal rows. Full-screen footers and manual scrolling retain their usual behavior.

Update Stoke on the computer serving the website, then reload the page. Other computers need Stoke open, the same approved account/vault, and **Let my other devices see and open my sessions** enabled under **Accounts → Devices & sync**. They do not need their own public Phone access URL.

This opens running sessions. Starting or resuming sessions, past chat history and file transfer remain on the target's own website or desktop app.

Includes the terminal-key improvements in beta.12 and the earlier beta.11 fixes. The broader [implementation roadmap](https://github.com/realvinn/stoke/blob/v1.0.0-beta.13/docs/roadmaps/2026-10-08-execution.md) remains in progress.

Downloads cover macOS Apple silicon and Intel, Windows x64 and ARM64, and Linux x64. Enable beta releases under **Settings → Updates** and check for updates, or install this exact beta from a terminal outside Stoke:

```sh
curl -fsSL https://stoke.vinn.dev/install.sh | STOKE_VERSION=1.0.0-beta.13 sh
```

Windows PowerShell:

```powershell
$env:STOKE_VERSION='1.0.0-beta.13'; irm https://stoke.vinn.dev/install.ps1 | iex
Remove-Item Env:STOKE_VERSION
```
