Stoke 1.0.0 beta 14: Remote usage and reopen closed tabs

- **Remote Claude usage:** remote desktop tabs show the connected host’s usage in the title bar, with the same bars and reset countdowns as local sessions. Open the chip to see the host and reading time. Each attached session’s account refreshes about once a minute, even when the host’s own usage chip is idle. Local and remote readers share cached readings and provider backoff.
- **Reopen closed tabs:** Ctrl+Shift+T on Windows/Linux and Cmd+Shift+T on macOS reopen recently closed tabs, most recent first. Conversations resume with their original account and launch options; remote tabs request a fresh connection to their original host session. Private chats, installers and sign-in tabs are excluded. Ctrl+T / Cmd+T still opens a new tab.
- Includes the recent SSH key labels, sharing controls, compact sign-in, sidebar profile editing and beta installer URL improvements.

Update both the host and the connecting desktop for remote usage. Enable beta releases under **Settings → Updates**, then check for updates.

Downloads cover macOS Apple silicon and Intel, Windows x64 and ARM64, and Linux x64.
